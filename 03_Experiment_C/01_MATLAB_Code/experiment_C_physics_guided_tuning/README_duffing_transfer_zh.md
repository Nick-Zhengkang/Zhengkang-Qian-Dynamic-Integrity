# 实验 C：双势阱迁移

## 直接运行

打开 `test_experiment_C_duffing_transfer.m`，点击运行。默认设置：

```matlab
mode='develop';
alphaValues=[0.2 0.7 1.0];
resumeDir='';
```

三个阻尼值，每个 5 个配置、10 个 seed，共 150 次完整 GA 实验。每次 GA 的外层轨迹预算为 100；之前还有逐点分类诊断，不包含在 150 次中。先只检查一个阻尼时，可将 `alphaValues=0.7`。

`mode='confirm'` 使用 31:60 的 30 个新 seed，三组阻尼共 450 次 GA 实验。只允许改动模式和预定阻尼列表；不要根据某组 LIM 误差为它单独修改比例常数。`mode='smoke'` 用于检查程序通路，不代表正式结论。

## 模型和迁移规则

本次模型为二次阻尼双势阱：

\[
\ddot x+\alpha|\dot x|\dot x-x+x^3=0,
\qquad V(x)=-\tfrac12x^2+\tfrac14x^4.
\]

目标平衡点为 (-1,0)，非目标势阱在 (1,0)，鞍点在 (0,0)，距离定义 W=I。模型势垒为 1/4，目标附近局部频率为 sqrt(2)，局部周期为 2*pi/sqrt(2)。这些值由已有物理估计函数计算，而不是复制 quadratic-cubic 的参数。

保留上一轮规则常数：eta=0.005，beta=0.005，每个局部周期 125 个输出采样点，衰减时间安全因子 1.5，最少 20 个局部周期。由本模型特征重新生成计算域、discr、至少 3 格的目标邻域、Ts 和初始 tfinal。原始 DynIn GA (`type_x0=1`) 及其内部 GA 参数保持不变。

同一模型的几组 alpha 可能生成相同网格和目标邻域，因为势阱几何没有变化；阻尼相关的时间估计仍会重新计算。这不属于跨模型照搬参数。

## 五组对照

| 配置 | 目的 |
|---|---|
| period_only | 仅用局部周期设积分时长 |
| double_period | 保持网格和目标邻域不变，只将时长加倍 |
| decay_estimate | 同一空间配置，采用物理衰减时长估计 |
| grid_first | 从 period_only 出发，依次检查网格、时长、采样间隔 |
| time_first | 从相同起点出发，依次检查时长、网格、采样间隔 |

是否采纳候选只取决于校准诊断。独立 holdout 点用于检查，不参与回调。参考 LIM 使用现有 Genda separatrix 表达式及数值求根实现，仅在配置选定后评分。

原来每项最多两次细化、最多两轮联合检查及资源上限也保留。超过限制时标记未验证，不能自动称为通过。双势阱测试可能揭示规则不充分，这也是有效结果；不要为了得到通过结果临时改变规则。

## 评价标准

运行开始前，在 `transfer_protocol.mat` 和 `evaluation_protocol.csv` 中记录：

- 主阈值：相对误差 <=2%。
- 同时报告 <=1%、<=2%、<=5% 的达标率。
- 经验筛选要求：至少 90% 的运行满足主阈值。
- false-safe、false-unsafe、未解析比例和稳定性诊断沿用上一轮要求，未放宽。
- 失败运行计入达标率分母，不能仅统计成功运行。

新汇总的 `primary_screening_pass` 表示主精度筛选、分类诊断和 GA 积分时长耗尽代理检查均通过；`primary_and_stability_pass` 还要求时间、网格、采样稳定性检查通过。未进行稳定性检查的固定对照配置，该字段为 false 不代表已经证明不稳定。

10 个 seed 中 9 个达标只是一项经验筛选，不是成功概率 >=90% 的统计保证。此次 2% 阈值是在查看 quadratic-cubic 开发结果后选择的，在本次双势阱运行前冻结；报告中应说明这个先后顺序。

## 查看哪些文件

优先查看新输出根目录：

- `raw_data_all_runs.csv`：所有已完成阻尼组的逐次结果，包含 model、alpha、seed 和三个阈值的布尔判定。`suite_run_key` 是跨阻尼唯一键。
- `summary_transfer_thresholds.csv`：每个 alpha、每个配置的误差、1/2/5% 达标率、时间和主筛选结论。
- `paired_contrast_summary.csv`：同一阻尼内配置间的配对误差变化和耗时比。
- `case_manifest.csv`：阻尼与 case_01、case_02、case_03 子目录的对应关系、完成数和计时复核数。

每个 case 子目录保留物理特征、调整日志、独立分类诊断、源文件快照和逐次 GA 断点。子目录的 `summary_transfer_thresholds.csv` 同样使用新评价口径。

**兼容说明：**为了不改变已运行代码及旧断点，底层调用已有 `run_experiment_C_rule_followup`。它生成的 `summary_by_profile_and_budget.csv` 仍是原来的 1% 口径。请使用新命名的 `summary_transfer_thresholds.csv` 作为本实验主报告；其中保留 `legacy_1pct_screening_pass` 便于追溯。阈值改变只影响评分，不改变参数选择或原始算法。

原有 `frozen_time_first.mat` 仍可用于后续预算实验，前提是分类准入通过。其准入不读取参考 LIM，也不依据 1%/2% 精度结果挑选参数。

## 进度与恢复

会显示 `[case 1/3]`、逐点诊断进度及 `[run 1/50]`。计算完成的 case 会写入根目录汇总；尚未完成的 case，其已完成运行可在 case 子目录查看。

中断后把 `resumeDir` 填为 `outputs_duffing_transfer_...` 根目录的完整路径，其余模式和 alpha 列表不变，再运行入口。不要填写旧 quadratic-cubic 文件夹，也不要填写 case 子目录。恢复会复用已完成的诊断和 GA 断点，只重跑中断的单次 GA。

不要在运行中更改源代码。恢复会校验源代码和设置，防止不同版本混在一起。尽量保持电脑唤醒；计时复核标记只能提示异常，不能证明所有未标记计时都没有系统干扰。

## 对实验 C 的判读

比较的是规则，而不是哪一个固定数字能通用于所有模型。重点检查：

1. 物理衰减估计是否比仅按周期估计更少出现未解析。
2. 时间优先能否在分类可靠的同时减少最终网格细化和运行成本。
3. 在预先约定的全部 alpha 上，分类诊断和 2% 精度标准是否仍通过，而非只报告表现好的阻尼。
4. 如果不通过，日志显示的失败属于时间、空间、误分类、资源上限还是搜索精度不足。

不要合并三个 alpha 的达标率后掩盖某个阻尼的失败；先逐案例评价，再讨论规则适用范围。最终确认还应使用新 seed。
