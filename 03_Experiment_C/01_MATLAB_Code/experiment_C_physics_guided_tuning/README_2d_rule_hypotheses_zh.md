# 实验 C：从物理特征生成参数，再用诊断决定是否调整

本实验检验的是可重复执行的调参步骤。同一组规则常数用于不同模型，但每个模型的 `discr`、目标邻域、`Ts` 和 `tfinal` 都重新计算。规则常数和判据目前都是候选假设，不能称为已经验证的普适结论。

入口：`test_experiment_C_2d_hypotheses.m`。原始 DynIn 使用 `type_x0=1`，本实验不修改它的 GA、轨迹分类或网格标记函数。

## 1. 四个主要假设

### H1：用物理尺度设置网格，再按诊断决定是否加密

从方程得到目标到最近鞍点的距离 Lx，以及势垒对应的速度尺度 Lv=sqrt(2*DeltaV)。设计算域宽度为 Dx、Dv，候选初值为：

```text
discr = ceil(max(Dx/Lx, Dv/Lv) / eta)
eta = 0.005
```

随后取奇数，并显式记录上下限的影响。这一公式使不同模型具有相近的无量纲网格宽度。

诊断：在同一组点上比较 N 和约 2N；加密时重新计算目标邻域，使其物理能量尺度近似保持不变。若误分类/未解析数下降且其他错误不增加，采用细网格并继续检查；若两个分辨率都通过分类要求且标签一致，保留便宜的较粗设置。若加密没有改善已经存在的问题，报告“网格无响应”，不将它称为通过。

对照：`grid_check` 对 `physics_only`。

能回答：这个物理网格起点以及诊断后加密步骤是否足够、是否值得其成本。不能仅由这个对照证明 eta=0.005 最优，也不能证明它优于所有固定网格设置。

### H2：目标邻域应按能量尺度设置，而非固定格数

初步尺度为 q=sqrt(beta*DeltaV/V''(xe))、v=sqrt(beta*DeltaV)，beta=0.005。脚本随后使用真实势函数和实际网格位置，检查目标格块的最大势能加最大动能，选择满足下式的最大奇数边长 k，并要求 k>=3：

```text
max energy over the entire target-cell rectangle <= beta*DeltaV
```

目标格块还必须完全位于目标势阱内。网格细化后 k 通常增加，但物理目标邻域近似保持不变。无法容纳安全的三格邻域时，规则明确失败，不能直接强行设为三格。

对照：`combined` 对 `combined_fixed_k3`。两者采用相同的其他检查程序；后者始终保持 k=3，因此加密后物理邻域会缩小。这是两个完整目标邻域规则的比较，不是“只改一个最终格数”的比较。

支持信号：能量尺度规则在不同模型上没有增加 false-safe，并减少 false-unsafe、超时或达到合格分类所需的成本。若目标格块虽满足能量约束，却在完整 GA 中仍表现不可靠，需要保留该反例。

### H3：局部周期加二次阻尼衰减估计可以提供积分时长起点

对于当前单位质量、二次阻尼的单自由度系统，局部频率 omega=sqrt(V''(xe))，周期 P=2*pi/omega。小振幅平均近似为：

```text
dA/dt approximately equals -c*A^2
c = 4*alpha*omega/(3*pi)
Tdecay = (1/Atarget - 1/Ainitial)/c
T0 = max(20*P, 1.5*Tdecay)
```

这里 Ainitial=min(Lx,Lv/omega)，Atarget 来自 H2 的物理能量尺度。这是局部近似，不能解释所有边界附近的慢轨迹，也不是严格时间上界。

诊断：比较 T 和 2T 的 DynIn 分类。标签改变且错误没有增加时采用更长时间；仍有未解析点时继续延长，直到通过或达到预设上限。“两次都不知道”绝不视为通过。若同一个已知目标点被提前判为新吸引子，单纯延长时间可能无效，记录这种信号。

两个对照分别回答不同问题：

- `time_check` 对 `physics_only`：时间校验步骤是否改善可靠性。
- `combined` 对 `combined_period_time`：衰减公式比只用 20P 更能减少后续调整成本吗？最终精度、诊断通过情况和调参成本必须一起看。

### H4：局部周期给出采样间隔起点，标签和轨迹距离共同校验

初值 Ts=P/125。诊断时比较 Ts 和 Ts/2。

除了分类标签，还比较同一条真实非目标轨迹上被采样到的最小加权距离。若最大相对变化超过 0.5%，即使标签相同，也继续检查更密的时间采样。这一检查只比较数值轨迹，不读取参考 LIM。

若减半 Ts 改善误分类/未解析且没有恶化其他错误，或最近距离尚不稳定，则采用较小 Ts 并复查；若两者都合格且结果稳定，保留较大的 Ts。达到下限仍不稳定则记为失败。

对照：`sampling_check` 对 `physics_only`。

## 2. 七个候选流程

| 名称 | 物理初值后的动作 |
|---|---|
| physics_only | 直接使用物理初值，作为规则校验步骤的对照 |
| grid_check | 只检查 N 与 2N |
| time_check | 只检查 T 与 2T |
| sampling_check | 只检查 Ts 与 Ts/2 |
| combined | 依次检查网格、时间、采样；后续修改后复查前面的步骤 |
| combined_fixed_k3 | 与 combined 相同，但目标邻域始终为三格 |
| combined_period_time | 与 combined 相同，但初始时间只取 20 个局部周期 |

`rep_periodic=10` 和 `rep_fix_point=40` 在这一轮保持一致。本实验尚不检验它们的物理换算公式。若出现 `n_new_attractor_false_unsafe>0`，说明后续应单独检验吸引子识别条件；不能把它强行归因于 tfinal。

计算域来自相同的势阱尺度与 20% 余量。初始点位于域外时记为 `domain_excluded`。域内出发、真实会返回目标却被 DynIn 判为出域的点记为 `n_domain_exit_false_unsafe`，这是计算域设置需要再检查的证据。本轮不会自动把扩大计算域的影响混入四个假设。

## 3. 调参与检验的数据分开

1. 校准点：12 个方向、5 个物理尺度半径；在实际观测到 target/non-target 转换的径向区间补 3 次中点查询。
2. 留出点：转过角度的另一组方向、4 个不同半径，并补 4 次中点查询。它们不参与参数选择。
3. 两组点使用独立的高精度正向积分与能量困陷条件确定最终势阱。QC 的向右逃逸、Duffing 的另一势阱和 cosine 的其他势阱分别处理。能量条件不能判定时继续积分；仍不确定则保留未知。
4. 原始 DynIn 分类器逐点运行，保存真实类别、预测类别、原始 tipo、终止原因、时间和最近距离。这里只初始化目标网格，不包含完整 GA 的历史标记，因此它是分类器诊断，不是完整算法误分类率的严格测量。
5. 完成七个流程的参数选择后，才计算解析参考 LIM，再做完整 DynIn GA 重复实验。

当前候选诊断门槛：至少 5 个真实目标点、5 个真实非目标点及 3 个已解析的边界附近点；观测 false-safe 为 0；false-unsafe 和分类未解析比例各不超过 2%；域内真值未解析不超过 5%；无分类器异常。

这些是有限诊断集上的工程判据，不是总体错误率的统计保证。域外初始点和真值未知点均单列；不会将它们计为分类器超时，也不会将它们算作分类正确。

## 4. 如何运行

首先使用默认设置：

```matlab
model = 'quadratic_cubic';
alpha = 0.4;
mode = 'develop';
resumeDir = '';
```

打开并运行整个 `test_experiment_C_2d_hypotheses.m`。入口会先执行快速辅助自检，通过后进入实验。不要继续使用旧的 `test_experiment_C_2d_rule.m` 来运行这个新设计。

- `develop`：7 个流程、10 个种子、每次 100 条轨迹，共 70 次完整 GA 运行；诊断在前，进度分别显示。
- `smoke`：仅用于检查程序能否运行，小诊断集、每次 5 条轨迹，不形成科学结论。
- `confirm`：30 个新种子 31:60，共 210 次完整 GA 运行。调参规则仍按模型特征重新执行。
- 后续分类规则稳定后，可设 `cfg.budgets=[100 200]`，在相同已选分类参数下研究搜索预算；预算不会反馈到分类调参。

中断后，将 `resumeDir` 填为本轮输出目录，保持模型、alpha、mode、cfg 不变，再运行。逐点诊断、逐次 GA 和参数选择检查均可恢复。源函数改变后会拒绝混用旧输出。

各流程在相同 seed 下使用相同的初始 RNG 状态，预算之间也相同；执行顺序单独随机化。由于算法路径可能分叉，这不保证它们访问完全相同的初始点。

## 5. 如何决定假设是否获得支持

先在 quadratic-cubic alpha=0.4 检查机制，再将候选流程原样运行于预先列出的其他情况：

| 角色 | 模型与阻尼 |
|---|---|
| 开发检查 | quadratic_cubic, alpha=0.4 |
| 阻尼变化 | quadratic_cubic, alpha=0.2, 0.8 |
| 双稳态迁移 | bistable_duffing, alpha=0.2, 0.7, 1.0 |
| 周期势迁移 | cosine_quadratic_drag, alpha=0.02, 0.05, 0.10 |

同一套规则常数、检查顺序和失败判据用于所有情况。更换模型后不复制最终 N/k/T/Ts，而是重新提取特征、执行流程。若根据留出模型结果改了规则，该模型也成为开发证据，应另找未参与修改的情况验证。

逐个假设同时看：

- 留出分类诊断是否通过，尤其是 false-safe 和未解析。
- 10/30 次完整 GA 的 LIM 相对误差、中位数、经验 P95、1% 达标率和大于 1% 的高估比例。
- 调参开销、算法运行时间及一次实际应用的总成本。
- 同一问题是否在不同模型或阻尼下重复出现。

当前性能筛选门槛是中位相对误差<=1%、至少 90% 的运行在 1% 内，同时分类诊断通过、完整 GA 无失败且无积分时限耗尽迹象。这些门槛写在 defaults 中，实验开始前确定；不要看到结果后逐模型放宽。

`meets_screening_criteria` 表示当前案例达到预设表现；`verification_pass` 表示该流程要求的细化检查确实完成；`ready_for_confirmation` 同时要求两者通过。单次、单模型通过不能证明跨模型可靠。

如果两个流程最后选择了同样的参数，它们可能产生完全相同的 LIM 结果。这本身是有用的结果：区别可能只在校验或调参成本，不能强行声称某个公式提高了最终精度。

## 6. 输出与成本

- `physical_features.csv`：模型特征、两种时间初值与请求的网格密度。
- `selected_parameters.csv`：每个流程在本模型上算出的最终设置及校准状态。
- `adjustment_log.csv`：每一次候选修改、诊断变化、是否采用和原因。
- `calibration_truth.csv` / `holdout_truth.csv`：两套点的坐标及独立标签。
- `classifier_cache/*.csv`：每个设置的逐点分类结果，可定位具体失败原因。
- `holdout_by_rule.csv`：未参与调参的分类检验。
- `raw_data_all_runs.csv`：完整 GA 的逐次结果。
- `summary_by_rule_and_budget.csv`：误差、分类诊断、时间和筛选状态。
- `hypothesis_comparisons.csv`：预先指定的假设对照差异，不自动输出统计显著性结论。
- `paired_contrasts_by_seed.csv`：相同 seed 下各假设对照的误差差值和时间比，保留失败配对。
- `run_checkpoints/*_history.csv`：完整 GA 的逐步 LIM、tipo 和耗时。

共享诊断缓存用于节省实际计算。每个流程的调参成本按它独立执行时需要的不同分类检查收费，即使本次程序读到了其他流程已经算过的缓存。独立留出检验和解析参考的成本单独报告，不混入每次 GA 时间。

原始 DynIn 使用 automatic=1 时会将未解析轨迹转为非目标。脚本记录时限耗尽代理指标；它不能恢复所有被转换前的内部信息。因此，零代理计数也不能作为完整算法分类绝对可靠的证明。
