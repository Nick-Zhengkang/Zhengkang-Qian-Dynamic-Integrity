# 实验 C：调参顺序、搜索预算与双势阱迁移

入口：`test_experiment_C_rule_followup.m`。在 MATLAB 编辑器中打开并运行即可。

这是新实验，不覆盖旧脚本、旧数据或原始 DynIn 函数。原算法保持 `type_x0=1`，GA 内部参数不变。新代码仅改变实验配置并记录诊断。

## 第一步：先运行默认设置

```matlab
stage='time_order';
mode='develop';
sourceDir='';
resumeDir='';
```

模型为 quadratic-cubic，alpha=0.4。5 个配置各运行 10 个 seed，外层搜索预算各为 100，共 50 次 GA 实验；前面还有独立分类诊断，因此总工作量不只是 50 次积分。

| 配置名 | 用来回答什么 | 如何设置 |
|---|---|---|
| period_only | 只按局部周期估计时长是否不足？ | 固定物理网格和目标邻域，T 为 20 个局部周期向上取整 |
| double_period | 同一网格下延长时间能否消除未解析？ | 仅把上一配置 T 加倍 |
| decay_estimate | 加入二次阻尼衰减估计是否给出更合适的起点？ | 仅换成物理衰减公式得到的 T |
| grid_first | 未解析时先细化网格会花多少额外成本？ | 从 period_only 开始，网格→时间→采样间隔 |
| time_first | 同样的诊断和调整候选，先检查时间是否更有效？ | 从相同 period_only 开始，时间→网格→采样间隔 |

本例前三项预计分别为 T=130、260、300，N=561、目标格数 k=15、Ts≈0.05027。这些数字是模型特征换算的结果，不是写死给所有模型用的参数。

前两个顺序实验使用完全相同的调整判据：

1. 固定诊断点，比较当前配置与候选配置的标签、误分类和未解析数量。
2. T 候选为 2T，网格候选约为 2N（调整为奇数），采样候选为 Ts/2。
3. 不增加任何错误分量、同时改善诊断的候选才被采纳；仍有未解析的延时候选可继续检查。
4. 两个配置均通过诊断且标签稳定，才保留当前配置并标记该项检查通过。采样还检查非目标路径最近距离变化。
5. 任一参数改变后，需要下一轮重新检查之前的项目。达到资源上限只表示无法验证，不表示通过。

注意：这里验证的是“先检查时间”的候选规则，并非先验认定任何错误都应通过延时修复。诊断显示错误变多时会拒绝该候选。

## 第二步：固定分类配置，再比较 100/200

等第一步完成后，仍使用同一个入口，改为：

```matlab
stage='budget';
mode='develop';
sourceDir='第一步输出文件夹的完整路径';
resumeDir='';
```

此阶段自动读取该文件夹的模型和 alpha，固定预先指定的 `time_first` 设置，只比较 100 与 200 次外层预算，10 个配对 seed，共 20 次 GA 实验。不会根据参考 LIM 或第一阶段误差选择获胜配置。

只有 `time_first` 的校准诊断、时间/网格/采样稳定性检查，以及独立 holdout 检查全部通过，才允许开始。否则明确报错，先分析失败原因。不能仅凭“两次标签不变”冻结全未解析的分类器。

记录 200 次运行在第 100 次时的 R，与单独 100 次运行核对。如果前缀不同，不能默认两者使用了完全相同的搜索路径。相同 seed 本身并不保证不同算法配置的搜索路径相同。

10 个 seed 用于开发筛选。独立确认时，设 `mode='confirm'`，沿用同一 sourceDir，使用 31:60 的 30 个新 seed，两预算共 60 次。不要把旧 10 个 seed 的重复运行算作额外独立样本。

## 第三步：双势阱检验

```matlab
stage='transfer';
mode='develop';
transferAlpha=0.7;
sourceDir='';
resumeDir='';
```

沿用第一步的五个规则和相同比例常数，针对 bistable Duffing 重新计算目标平衡点、势垒、局部频率、空间尺度、计算域、网格、目标邻域和初始积分时长。共 50 次 GA 实验。之后可预先约定在 alpha=0.2、1.0 重复，避免看见结果后再挑选有利阻尼。

双势阱阶段的 time_first 通过后，也可以将其输出文件夹用于 budget 阶段。不要给双势阱手动填入 quadratic-cubic 的 N、k、T。

## 物理假设与参考值

继承上一版的可检验假设：相对网格尺度 eta=0.005，目标邻域能量比例 beta=0.005，Ts=P/125，二次阻尼局部振幅衰减提供积分时长起点。它们不是已证实的通用最优常数。

目标格数始终是至少 3 的奇数，检查实际格子覆盖区域的能量。换网格后，整数格子舍入可能改变实际目标邻域大小；日志记录其物理尺寸和能量比例，因此不把顺序对比称为严格的“纯网格效应”。前三个固定网格的时间对照才隔离了时间的作用。

解析参考 LIM 只在选定配置并完成独立分类检查后用于评分，不进入参数估计或候选选择。能量约束及更严格的正向积分提供诊断点标签；这仍是有限点集验证，不是全域准确性证明。

## 输出与如何判读

| 文件 | 内容 |
|---|---|
| physical_features.csv | 本模型的物理特征及时间估计来源 |
| prespecified_starting_profiles.csv | 五个规则的共同起点和时间对照 |
| adjustment_log.csv | 每次候选设置、诊断信号、接受/拒绝原因 |
| selected_parameters.csv | 最终配置及校准通过状态 |
| holdout_by_profile.csv | 未参与调整的诊断点上的误分类、未解析比例 |
| frozen_time_first.mat | 在计算参考值前保存的预算实验配置及准入标志 |
| raw_data_all_runs.csv | 每次 GA 的 R、误差、时间、seed、状态 |
| summary_by_profile_and_budget.csv | 各配置的误差、1%达标率、时间及分类诊断 |
| paired_contrasts_by_seed.csv | 配对误差差值和耗时比，candidate 减 comparator |
| paired_contrast_summary.csv | 配对差值中位数、改善/变差次数、耗时比 |
| run_checkpoints | 每次完成的 MAT 断点及 R 随迭代变化的 CSV |

顺序规则得到支持，需要时间优先消除未解析且不增加误分类，并减少必要的网格细化或成本；预算不足假设得到支持，需要分类器固定时 200 次比 100 次提高准确性/达标率。迁移成功需要这些规律在双势阱重新生成参数后仍成立。单一模型单个 alpha 不能证明跨模型普适性。

达标率暂采用相对误差不超过 1%，筛选要求为至少 90% 成功；10 个 seed 达标并不构成真实成功概率达到 90% 的统计保证。停滞的 R 曲线也不是精度证书。这里仍不是“达到精度的最短时间”实验，而是两个固定预算的配对效果比较。

## 时间记录与恢复

- 每条轨迹诊断和每次 GA 都有进度输出。诊断点和已完成的 GA 可以恢复；中断的单次 GA 会从该次开头重跑。
- 恢复时把 `resumeDir` 设为本阶段输出文件夹，其他设置保持一致。budget 阶段还要保留原 sourceDir。不要拿旧版 hypotheses 输出作为新版的恢复目录。
- 保存并核对原始函数和实验辅助函数快照，源代码变化时拒绝混跑。脚本不修改现有旧版断点。
- wall time 包含休眠、暂停和其他系统干扰；新增 CPU 时间、开始/结束时间以及人工复核标记。标记条件是 wall>30 秒且 wall>5×max(CPU,1秒)，仅作提示，既不能确诊休眠，也不能排除所有计时异常。
- 不自动删除异常时间。汇总保留全部计时并报告复核数量；GA 耗时、共享诊断成本和各规则理论上需要的诊断成本分开记录。缓存共享可节约实际运行，但不能把缓存读取时间当作调参成本。
- 请避免计算中盖上电脑让系统休眠。配置数量大时先用 `mode='smoke'` 检查通路；smoke 不是科学结果，也不能提供正式冻结配置。

可先运行 `test_experiment_C_followup_helpers` 与已有 `test_experiment_C_rule_helpers` 做快速检查。完整数值实验仍需要在 MATLAB 中运行。
