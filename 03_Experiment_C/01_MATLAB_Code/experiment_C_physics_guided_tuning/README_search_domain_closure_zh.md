# 实验 C：计算域必须覆盖其允许的 GA 初始点的后续轨迹

## 本次补齐的环节

先计算原始 DynIn GA 的整个初始搜索球所能达到的最大能量，再构造覆盖该能量下
全部轨迹的计算域。构造完成后重新计算 DynIn 的初始搜索半径，检查前后相同。
本次只运行计算域审计和轨迹覆盖检查，不运行完整 GA，也不读取参考 LIM。

适用条件：二次阻尼双势阱 Duffing，alpha>0，目标 (-1,0)，距离权重 W=I，
原始域的左侧 x 边界决定初始半径。脚本遇到其他模型或权重会明确停止。

## 为什么整个搜索球的能量上界可以直接计算

方程为 x'' + alpha |x'| x' - x + x^3 = 0。

E(x,v)=v^2/2-x^2/2+x^4/4，dE/dt=-alpha |v|^3<=0。

原始 GA 使用 R0=min(-1-xmin, xmax+1, -vmin, vmax)。后续 R 只减不增，
随机个体、交叉结果和 clones 都限制在当时的球内，因此所有查询都在初始球中。
本次结论只针对 type_x0=1，不针对有 1.1R 外扩选点的其他分支。

令 u=x+1。当 u^2+v^2<=R0^2 时：

E=-1/4+v^2/2+u^2-u^3+u^4/4
 <=-1/4+R0^2/2+u^2/2+|u|^3+u^4/4
 <=-1/4+R0^2+R0^3+R0^4/4。

等号在 (x,v)=(-1-R0,0) 取得。因此 Ecap 是整个球的精确最大能量，
不依赖有限诊断点是否碰巧取到高能量位置，也不依赖解析 LIM。

由 E(t)<=Ecap，可得所有轨迹均满足：

|x|<=1+R0，|v|<=R0(R0+2)/sqrt(2)。

## 保持搜索半径的构造

固定 xmin=-1-R0，向右扩展 x 上界，向正负速度方向扩展速度边界。
在三个可扩展边界外增加至少两格数值余量。所有扩展均采用整数格数。
由于原始函数使用单个 discr，各坐标方向增加相同的总格数，但左右分配不同。
这样可以同时保留物理网格宽度、网格对齐、目标邻域和 R0。

左边界不增加余量是有意的：只要原始查询严格位于搜索球内，其能量严格小于
Ecap，精确连续轨迹就不会到达该边界。闭球极端点恰在边界，原代码的严格域内
判据及浮点积分仍需单独检查。脚本在距离该边界很近的位置加入压力测试。
几何覆盖证书不等于浮点实现对任意近边界点都具有严格保证。

## 怎样运行

在 MATLAB 打开 test_experiment_C_search_domain_closure.m，点击 Run。
默认 mode='validate'：三个 alpha，每个 alpha 比较原始域、旧对称能量域、新的
固定左边界能量域。每个域检查其自身搜索球的 81 个初始点，共 729 个轨迹探针。
用 mode='audit' 可以只做数学和网格审计，不积分。

每条轨迹完成后保存，屏幕持续显示 [probe i/81]。中断后将输出目录填入
resumeDir。入口脚本不纳入恢复时的源代码一致性检查，允许修改 resumeDir。

轨迹直接用方程积分，不以计算域越界为停止条件。达到 E=-0.01 后停止，并用
终点能量包络覆盖未积分的未来。如果达到 tfinal 仍未触发，也检查终点能量包络。
因此“未触发事件”不被等同于非目标，且覆盖检查不需要知道最终属于哪个吸引子。

## 输出与通过条件

- search_domain_audit.csv：每个域的实际 R0、完整搜索球 Ecap、所需边界与覆盖结果。
- summary_trajectory_coverage.csv：轨迹越界、能量数值检查、未积分尾段覆盖。
- coverage_decisions.csv：是否允许进入下一轮完整 GA 对照。
- case_*/anchored_search_energy/coverage_settings.mat：冻结后的 g、p、audit。
- all_trajectory_probes.csv：所有探针的坐标与诊断结果。

只有几何覆盖、保持 R0、网格资源约束和全部轨迹检查同时通过，
ready_for_next_controlled_GA 才为 true。audit 模式永远不会标为已完成轨迹验证。
任何失败都留在表中，不因能量公式正确而被忽略。

本次各域按照自身允许的搜索球布点，不能把三者的探针越界比例解释成同点分类
准确率对比。新域与原始域的 R0 相同，因此两者探针坐标一致。旧对称域的探针
范围更大，这正是本次要检查的反馈。

## 本次不能回答的问题

该检查证明或检验轨迹是否有足够积分空间，不检验网格分类是否准确，也不证明
LIM 搜索已经充分。即使通过，仍需后续完整 GA 对照查看误差、分类和计算时间。
现有独立分类诊断对旧能量域的结果不能直接当作新域已通过分类验证。
