The repository covers Experiment~A, the multi-damping-value Bayesian search
and frozen cross-model transfer in Experiment~B, the physics-guided procedures
in Experiment~C, and the comparison between the original DynIn GA and the
adaptive angular--radial method. Its README gives software requirements,
entry points and pilot/full-run settings. Selected CSV exports are accompanied
by source-dataset identifiers and checksums; the repository is not a complete
archive of individual trajectories and run checkpoints.

The original DynIn implementation is available separately at:

\begin{center}
\url{https://github.com/GlobalDynamicsRG/DynIn}
\end{center}

The included native subset is based on DynIn v1.1.0. The upstream commit is
identified in the repository README. The original GPL-3.0 license and
attribution are retained; the thesis-specific scripts and proposed search
method are distinguished from the upstream implementation.
\end{greenrevision}
